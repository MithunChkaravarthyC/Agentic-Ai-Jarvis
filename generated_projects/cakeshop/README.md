# CakeShop

## Features

* Product catalog with images and prices
* Add to cart and remove from cart functionality
* Cart summary with total cost
* Checkout button for simulated payment

## How to Use

1. Run the application by opening the `index.html` file in a web browser.
2. Browse the product catalog and add items to your cart.
3. View your cart and remove items as needed.
4. Checkout and simulate a payment by clicking the "Checkout" button.

Note: This application is for demonstration purposes only. It does not store data or process payments in a real-world scenario.
