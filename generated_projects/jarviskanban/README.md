# Jarvis Kanban

A Kanban board with columns Todo, Doing, and Done, featuring drag-and-drop support.

## Features

* Kanban board with Todo, Doing, and Done columns
* Drag-and-drop support for moving cards between columns
* Local storage persistence for card positions

## How to Use

1. Open the index.html file in a web browser
2. Click and drag a card to move it between columns
3. Use the Todo, Doing, and Done columns to organize your tasks

Note: This project uses modern JavaScript and CSS features. Make sure your browser supports these features before running the application.
