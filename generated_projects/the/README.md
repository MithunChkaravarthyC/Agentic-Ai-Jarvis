# Hotel Mommy's Kitchen

### Project Overview

Hotel Mommy's Kitchen is a modern web application designed to provide a warm and welcoming dining experience for customers. This project aims to enhance the existing website with animations and a professional design, while maintaining the core features and functionality.

### Features

* Responsive design for optimal viewing experience across various devices and browsers
* Animations for buttons and sections for visual appeal and user engagement
* Semantic HTML5 structure for improved accessibility and SEO
* Polished CSS styling for a modern and professional look
* Client-side logic using JavaScript for dynamic UI states and localStorage persistence

### How to Use

1. Visit the website at [https://hotel-mommys-kitchen.com](https://hotel-mommys-kitchen.com)
2. Explore the website's features, including the menu, contact form, and learn more buttons
3. Use the contact form to get in touch with Hotel Mommy's Kitchen
4. Enjoy the animations and design elements throughout the website
