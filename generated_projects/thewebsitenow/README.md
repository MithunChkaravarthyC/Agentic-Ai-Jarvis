# TheWebsiteNow

TheWebsiteNow is a production-ready, ultra-smooth 3D web application inspired by Lusion (lusion.co). This project showcases a modern, immersive 3D experience with advanced graphics, interactive elements, and a sleek user interface.

## Features

- **3D Torus Knot**: A complex, organic geometry with realistic lighting and materials.
- **Smooth Mouse Parallax**: Buttery-smooth camera rotation using lerping.
- **Interactive HUD**: Wireframe mode toggle, particle count slider, color theme switcher, auto-rotation toggle, and camera reset.
- **Dynamic Lighting**: Multi-point cinematic lighting with ambient, directional, and dynamic point lights.
